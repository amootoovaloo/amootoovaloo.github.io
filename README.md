# amootoovaloo.github.io

Source of [amootoovaloo.github.io](https://amootoovaloo.github.io), the personal website of Arrykrishna Mootoovaloo.

## Preview locally

```sh
bundle install
bundle exec jekyll serve --livereload
```

Open http://127.0.0.1:4000; pages refresh automatically when you save a file.

## Publish

Push to `master`; the site updates within a couple of minutes.
